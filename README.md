# श्री गणेशोत्सव २०२६ - बासुदकर परिवार निमंत्रण
### *Shree Ganeshotsav 2026 - Basudkar Family Invitation*

A festive, interactive, and bilingual (Marathi & English) digital invitation web experience created for the **Basudkar Family's Ganeshotsav 2026** celebration with the sacred Tirupati Balaji theme.

---

## ✨ Features
- 🪔 **Divine Entrance Gate**: Balaji Namam / Tilak with sacred animations and temple bell chime.
- 🌺 **Ambient Flower Shower**: Physics-based interactive marigold & rose petal cascade.
- 🎵 **Devotional Audio System**: Authentic Aarti music and synthesized temple bell resonance.
- ⏳ **Live Countdown Timer**: Real-time countdown to Ganesh Sthapana (*14th September 2026, 12:00 PM*).
- 📜 **Formal Family Invitation**: Traditional Sanskrit shlokas, heartfelt family invitation, and family portrait.
- 📅 **Festival Program Schedule**: Day-by-day itinerary with exact timings for Sthapana, daily Pooja, and Visarjan.
- 📍 **Venue & Navigation**: Residence address (*Khatav Building, Lalbaug, Mumbai*) with integrated Google Maps directions.
- 📷 **Past Years' Darshan Timeline**: High-resolution gallery of past celebrations (2023, 2024, 2025).
- 📥 **One-Click Invitation Card Generator**: High-resolution greeting card export rendered on Canvas.
- 🌐 **Bilingual Support**: Instant toggle between Marathi (मराठी) and English.
- 📱 **100% Mobile & Desktop Responsive**: Tailored layout for all screen sizes.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Using Python built-in HTTP server
python -m http.server 3000
```

Then visit: `http://localhost:3000/`
